# Roadmap

## Phase 1 — playable MVP

- [ ] Web app shell and responsive game layout
- [ ] Isometric map rendering and camera controls
- [ ] Starter kingdom and server-owned player state
- [ ] Resource production and storage caps
- [ ] Building placement, upgrade costs and build timers
- [ ] Missions and progression
- [ ] PostgreSQL schema, migrations and seed data
- [ ] API validation, rate limits and audit trail
- [ ] Automated tests and CI

## Phase 2 — multiplayer and economy hardening

- [ ] Server-authoritative combat
- [ ] Leaderboards and seasonal scoring
- [ ] Anti-abuse and reward eligibility controls
- [ ] Admin operations and audit review

## Phase 3 — Robinhood Chain testnet

- [ ] Verify current chain configuration
- [ ] Deploy and verify contracts using a dedicated test wallet
- [ ] Wallet sign-in and NFT ownership gating
- [ ] Test token and reward claims with test assets only

## Phase 4 — launch readiness

- [ ] Confirm OpenSea support for the target chain
- [ ] Finalize tokenomics and legal review
- [ ] Independent contract and application security review
- [ ] Fund and disclose any reward pool
- [ ] Explicit approval before any mainnet deployment or paid mint
